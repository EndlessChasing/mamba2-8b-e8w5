## Model and software scope

The repository software uses GPL-3.0 for the E8/LDLQ-derived implementation lineage. The upstream model's Apache-2.0 designation is recorded separately; using a GPL quantizer does not by itself relicense every input or output. Any shipped codebook or source-derived resource must retain its software provenance instead of being silently labelled as ordinary model weights. Quantized weight releases must prominently state that the weights were modified from the NVIDIA checkpoint and include upstream attribution and applicable license texts.

QuIP# authors: Albert Tseng, Jerry Chee, Qingyao Sun, Volodymyr Kuleshov, and Christopher De Sa. Paper: [QuIP#: Even Better LLM Quantization with Hadamard Incoherence and Lattice Codebooks](https://arxiv.org/abs/2402.04396).

NVIDIA model authors and citation are retained verbatim in `NVIDIA_MAMBA2_MODEL_CARD.md`. This release is an independent quantization effort, with no claim of NVIDIA or QuIP# author endorsement.

## Excluded research material

Quamba is referenced as a public research comparison. Its [model repository license.txt](https://huggingface.co/ut-enyac/quamba2-8b-converted-w4a16/blob/997f760f29c10574ee8363b8680d636048dee048/license.txt) states UT Austin Research License restrictions, including restrictions on redistribution and commercial use. Some model card tags differ. No Quamba source or documentation is copied into this repository, and its implementation is not a dependency of this release.

Private Resurface code, adapter checkpoints, private datasets, and historical experiment archives from the earlier private research project are outside this release. The new public `mamba_e8w5/resurface_native.py` implementation, synthetic-data generator and adapter trained for this repository are included in `v0.2.0-resurface`; they are distinct from those excluded private materials. The implementation is a post-D Resurface-inspired variant, not a claim of an exact upstream implementation. Its software is covered by the repository GPL-3.0 license. Model/software scopes above and the applicable retained notices continue to apply.

## Calibration and evaluation data

[WikiText](https://huggingface.co/datasets/Salesforce/wikitext/blob/b08601e04326c79dfdd32d625aee71d232d685c3/README.md) is fetched separately at revision `b08601e04326c79dfdd32d625aee71d232d685c3`, configuration `wikitext-2-raw-v1`. Its pinned dataset card lists `cc-by-sa-3.0` and `gfdl` in metadata; its licensing prose links CC BY-SA 4.0. This project preserves that upstream discrepancy instead of assigning a single unsupported SPDX expression. Dataset attribution: Stephen Merity, Caiming Xiong, James Bradbury, and Richard Socher, [Pointer Sentinel Mixture Models](https://arxiv.org/abs/1609.07843), 2016.

The public repository distributes download instructions, split/revision identifiers, hashes, window positions, and aggregate measurements. It does not redistribute WikiText text or tokenized passages. Synthetic key-value recall prompts are generated by this project's public protocol and are reported separately.
